# Recursos visuales

Coloca aquí los recursos del proyecto:

- `logo_insight_lub.svg`: logotipo oficial vectorial, listo para la aplicación y presentaciones.
- `banner_insight_lub.png`: imagen principal, si se desea reemplazar el banner CSS.
- `diagramas/mer.png`, `diagramas/modelo_relacional.png`, `diagramas/data_warehouse.png`: diagramas para la página Diagramas.

La interfaz funciona sin estos archivos; son marcadores para incorporar los recursos finales sin alterar el código.
